# SECURITY_GUIDE

작성일: 2026-04-04

## 1. 비밀정보 관리
- `.env*`는 기본 커밋 금지
- API 키/토큰/인증서 하드코딩 금지
- 로그/에러 메시지에 민감 정보 출력 금지

## 2. 의존성 보안
- 신규 의존성 도입 시 유지보수 상태 확인
- 정기 취약점 점검 수행
- 취약점 대응은 patch/minor 우선, 불가 시 대체 라이브러리 검토

## 3. 서드파티 코드 관리
- `vendor/`는 서브모듈 원본 추적 유지
- `patches/` 변경 시 영향 범위와 이유를 문서화
- 외부 코드 직접 수정은 승인된 케이스에서만

## 4. 런타임 보안 기본
- API route 입력 검증 필수
- 에러 메시지 최소 공개(내부 스택 노출 제한)
- 브라우저 전용 API 접근 시 환경 가드 적용

## 5. 공급망/릴리즈 보안
- lockfile 포함으로 재현 가능한 설치 유지
- 릴리즈 전 dependency 변경점 확인
- 의심스러운 패키지 업데이트는 격리 브랜치 검증

## 6. 사고 대응
1. 노출/취약점 식별
2. 영향 범위 파악
3. 임시 차단/롤백
4. 영구 수정
5. 사후 기록(원인/대응/재발 방지)
