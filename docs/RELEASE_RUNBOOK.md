4. 최종 검증(빌드 + 테스트)

## 3. 롤백 절차
1. 장애 범위 확인
2. 직전 안정 태그/커밋으로 롤백
3. 롤백 후 smoke 체크
4. 원인/재발 방지 기록(ADR 또는 이슈)

## 4. hotfix 절차

- 배포 후 본선 브랜치에 즉시 역병합
