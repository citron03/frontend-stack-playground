---
name: debug
description: Systematic debugging for web/tanstack/design-system apps.
---

1. Reproduce with the smallest possible scope.
2. Note runtime (Next.js, Vite, Storybook) and error surface (console, test).
3. Identify recent changes or suspect files.
4. Propose the minimal fix; avoid broad refactors.
5. If uncertain, add a small diagnostic log or test.
